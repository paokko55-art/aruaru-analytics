プライバシーポリシー

「あるある研究所 分析ツール」（以下「本ツール」）は、YouTube チャンネル「ガルちゃんあるある研究所」の運営者が、自分のチャンネルの数字を確認するためだけに使う個人用のプログラムです。

1. 取得する情報

運営者本人が Google アカウントで許可したときに、次の読み取り専用の権限を使って、運営者自身のチャンネルの情報だけを取得します。

  • YouTube Data API（youtube.readonly）: 動画の一覧・タイトル・公開日・再生数などの公開情報
  • YouTube Analytics API（yt-analytics.readonly）: 視聴回数・視聴時間・インプレッションなどの集計値

他の人の個人情報や、視聴者を特定できる情報は取得しません。

2. 使い方

取得した情報は、運営者がチャンネルの企画と改善のために、集計表やレポートを作ることだけに使います。

3. 保存と共有

  • 取得した情報と認証情報（トークン）は、運営者のパソコンの中だけに保存します。
  • 第三者への提供・販売・公開はしません。
  • 広告や、他の目的には使いません。

4. 権限の取り消し

運営者は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、いつでも本ツールのアクセスを取り消せます。取り消すと、本ツールは情報を取得できなくなります。

5. Google API サービスの利用

本ツールによる Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube のデータの扱いは YouTube 利用規約 と Google プライバシーポリシー にも従います。

6. 変更

このポリシーを変えるときは、このページを更新します。
